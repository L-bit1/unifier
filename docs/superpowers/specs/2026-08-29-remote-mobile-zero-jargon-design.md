# 2026-08-29 · 异网手机遥控（零术语）

## 目标体验

- **电脑**：安装/打开联合器 → 打开「让手机在外面也能用」→ 一键复制连接信息。
- **手机**：粘贴电脑复制的内容（或分别填地址/连接密码）→ 即可派活。
- 界面与文档**不出现**：隧道、Cloudflare、端口、SSH、frp 等词。

## 行为

1. 开启后：确保 Hub + 收件箱在跑；生成（或复用）连接密码；启动内置公网映射；展示连接卡。
2. 关闭后：停止映射；局域网/`127.0.0.1` 仍可用。
3. 异网开启期间：手机 API 必须带连接密码；本机 loopback 请求可免密（工作站脚本）。
4. 失败文案用人话（电脑关了 / 密码不对 / 暂时连不上）。

## 技术落点（对用户隐藏）

| 组件 | 实现 |
|------|------|
| 公网映射 | 桌面 runtime 内置/按需拉取 `cloudflared`，`tunnel --url http://127.0.0.1:8787` |
| 连接密码 | `UNIFIER_ACCESS_TOKEN`，请求头 `X-Unifier-Token` |
| 连接卡文案 | Hub 地址 + 连接密码 + 会话 ID，一键复制 |
| 手机 | Preferences 存 hubUrl / accessToken；`fetch` 自动带头；支持整段粘贴解析 |

## 非目标

- 自建 SaaS 中继云、自有域名强制
- 全自动无人值守 Cursor
- 要求用户理解或安装任何额外手机 App
