# 2026-08-29 · 手机在外面也能用（零术语异网访问）

## 目标体验

| 端 | 用户动作 |
|----|----------|
| 电脑 | 打开联合器 → 打开「让手机在外面也能用」→ 点「复制给手机」 |
| 手机 | 设置里粘贴电脑复制的内容（或分别填地址 / 连接密码）→ 保存 |

界面与文档**不出现**：隧道、Cloudflare、端口、8787、SSH、frp、Token（对外称「连接密码」）。

## 行为规则

1. 开关关闭：仅本机 / 局域网 / adb reverse；mobile API 可不校验密码（本机便利）。
2. 开关打开：
   - 确保 Hub 在跑；
   - 启动**内置映射进程**（实现可用 cloudflared quick tunnel，对用户不可见）；
   - 生成随机「连接密码」，写入本机配置；
   - 展示连接卡：地址 + 连接密码 + 复制全文；
   - 异网请求必须带连接密码，否则 401。
3. 关掉开关或退出联合器：停映射；手机提示「电脑上的联合器好像关了」。
4. 本机 `127.0.0.1` / `::1` 访问可免密（桌面自检、本机脚本）。

## 复制全文格式（手机可解析）

```
联合器连接
地址：https://….trycloudflare.com
连接密码：xxxxxxxx
会话：default
```

## 非目标

- 不要求用户自备 VPS / 域名 / 再装 App
- 不做完整 SaaS 中继云（本版用临时公网映射即可）
- 不承诺映射 URL 永久不变（每次开启可能新地址，需重新复制）

## 风险与文案

| 情况 | 用户可见文案 |
|------|----------------|
| 映射进程失败 | 暂时没法让手机从外面连，请检查网络后重试 |
| Hub 未起 | 正在准备本机服务… |
| 密码错误 | 连接密码不对，请回电脑重新复制 |
| 连不上 | 电脑上的联合器好像关了，打开后再试 |
