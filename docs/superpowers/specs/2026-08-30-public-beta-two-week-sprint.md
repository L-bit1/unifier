# 联合器 · 公开公测前两周冲刺（2026-08-30）

目标：**陌生人能下、能装、能用上「手机派活」**（不做全自动 Cursor）。  
公测形态：官网/Release 可下安装包 + 3 步说明；你少盯场。

## 两周只押 3 件事

| # | 主题 | 两周结束时的验收 |
|---|------|------------------|
| A | **安装包** | Mac（至少 arm64）+ Win 有可双击安装物；装完托盘起来；不必懂终端 |
| B | **异网续连** | 「外面也能用」失败/地址变化时，界面说人话；连接卡可一键再复制；说明写清「电脑要开着」 |
| C | **崩溃自愈** | Hub/收件箱挂了托盘能拉回；休眠唤醒后 1 分钟内可再连；有「一键修复」按钮 |

非目标（两周不做）：OA 真审批、里程碑 Hook 真推、SaaS 账号体系、全自动开会话。

---

## Week 1（安装 + 说明最小闭环）

### Day 1–2 · 安装包链路
- [ ] `desktop` 打通 `npm run build:mac` / `build:win` 产物可装
- [ ] 打包进 hub 运行时（或首次启动自动准备 venv），避免「缺 Python」白屏
- [ ] 安装后首次打开：自动起托盘 + 守护；Hub 健康显示为人话「本机服务已就绪」

### Day 3–4 · 三步说明书（零术语）
- [ ] 一页图文：`1 电脑打开联合器 → 2 打开「外面也能用」并复制 → 3 手机粘贴保存`
- [ ] 挂到 `desktop` 关于页 / README 公测节 / 可选 mishilost 一条
- [ ] 边界写清：要电脑开着；不做无人值守；地址变了重新复制

### Day 5 · 熟人预演
- [ ] 找 1～2 人按说明书从零安装（你不口头提示）
- [ ] 记卡点清单（权限弹窗、杀毒、Wi‑Fi、休眠）

---

## Week 2（异网稳定 + 自愈）

### Day 6–7 · 异网体验
- [ ] 打开失败：文案「暂时没法让手机从外面连，请检查网络后重试」（已有则压测补强）
- [ ] 地址变更：再次打开后高亮「请重新复制给手机」
- [ ] 托盘菜单常驻「复制给手机」；关闭外面访问时提示「同一 Wi‑Fi 仍可用」

### Day 8–9 · 崩溃 / 休眠自愈
- [ ] daemon 已有 supervise：补「一键修复」= 停映射 + 重启守护 + 可选重开外面访问
- [ ] 休眠唤醒：探测 Hub 掉线则自动拉起（限个人版本机）
- [ ] 日志：`~/.unifier/logs/` 保留最近错误，修复按钮可「复制日志给开发者」

### Day 10 · 公测门槛 Checklist
- [ ] 干净 Mac / 干净 Win 各走通：安装 → 外面也能用 → 手机粘贴 → 派一条活 → 确认执行
- [ ] 安全：有连接密码时 mobile API 必须校验（已做则回归）
- [ ] 出 `PUBLIC-BETA.md`：已知问题 + 反馈渠道（飞书/邮件/Issue）
